PUBLISH WITH GITHUB PAGES (FREE)
1. Sign in or create an account at https://github.com
2. Click the + icon near the top-right and choose "New repository".
3. Repository name: lucky-catering-website
4. Choose Public. Select "Add a README file" if shown, then create the repository.
5. In the repository, choose Add file > Upload files.
6. Upload index.html, style.css and script.js from this folder (upload the files themselves, not the ZIP).
7. Click "Commit changes".
8. Open Settings > Pages.
9. Under "Build and deployment", select "Deploy from a branch".
10. Select branch "main" and folder "/ (root)", then Save.
11. Wait a few minutes and refresh the Pages settings page. GitHub will show your published website URL.
